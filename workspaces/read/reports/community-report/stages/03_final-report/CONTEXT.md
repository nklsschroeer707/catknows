# Stage 03 — assemble the report

## Inputs
- (working) `../02_write-chapters/output/chapters/*.md` — approved
- (working) `../01_collect/output/manifest.md` — for the coverage note

## Process
1. Write the executive summary first: five bullets max — what the busy
   reader must know. Then the chapters in a sensible order (people →
   conversations → learning → ahead → numbers → outside view).
2. One connecting sentence between chapters where it helps the thread; no
   filler.
3. End with a small print line: which sources were fresh, stale, missing
   (from the manifest).
4. Archive the previous report to `output/archive/<date>.md`, then write
   the new one. If the human asked for a vault copy, mirror it per
   `output-style.md`.

## Outputs
- `latest.md` → `output/`

## Completion
Done when the summary alone would survive being read out loud in a meeting —
and every claim in it traces back to a chapter.
