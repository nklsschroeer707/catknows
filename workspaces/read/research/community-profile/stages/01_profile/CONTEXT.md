# Stage 01 — build the profile

## Inputs
- (parameter) `community_slug` — a skool.com URL works too, take the part
  after the domain

## Process
1. `get_community_about(community_slug)`.
2. Write the profile: what it is (2–3 sentences), the facts (members, price,
   owner, founded if visible), and your honest read — does the pitch feel
   substantial or thin?
3. Close with: is the logged-in account a member? If yes, name which other
   workspaces now apply (posts, members, classroom).

## Outputs
- `latest.md` → `output/`

## Completion
Done when someone can decide "join / skip / look closer" from this one page.
No further stages.
