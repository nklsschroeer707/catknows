# catknows / skool-api

Unofficial Skool API client + MCP server ("catknows"), plus an ICM workspace
catalog for running Skool jobs with AI agents.

## Where to go

| You want to… | Go to |
|---|---|
| Work on the catknows code (client, MCP server, docs) | [AGENTS.md](AGENTS.md) |
| Run a Skool job (members, posts, reports, …) | [workspaces/START-HERE.md](workspaces/START-HERE.md) |

Pick one lane. Code work never needs the workspaces; workspace runs never
need the Python source — the catknows MCP tools are the interface.
